# A little love ♡

A responsive, static surprise website published through GitHub Pages.

- Open `index.html` directly or serve this directory with any static web server.
- Entry code: `0801`, editable in `app.js`. This is a playful client-side gate, not authentication; do not store private information here.
- Seven pages: welcome, note, gifts, letter, music, memory, and thank-you.
- The music page plays an original synthesized music-box melody after an explicit click. Replace it with your chosen licensed audio if desired.
- Text is editable in `index.html`. No build step, frameworks, remote fonts, or third-party runtime dependencies.
- Desktop entry art is the supplied reference. Mobile scenes are newly generated artwork based on the reference, not a pixel-identical reproduction.
- `assets/art/scenes.webp` contains six full scenes in a 3 × 2 atlas. Controls and text remain real accessible HTML.
- Pixel font: Press Start 2P under the SIL Open Font License in `assets/fonts/OFL.txt`.

Checked in Chromium at mobile and desktop widths: correct/incorrect code, keyboard input, page navigation, letter opening, user-initiated audio, and horizontal overflow.
